## 😊 Task 2 — Twitter/X Sentiment Analysis

### Objective

Perform sentiment analysis on social media posts using the **VADER Sentiment Analyzer**.

### Workflow

- Import Dataset
- Data Cleaning
- Text Preprocessing
- Sentiment Classification
- Data Visualization
- Result Interpretation

### Technologies

- Python
- Pandas
- NLTK
- VADER
- Matplotlib
- Seaborn

### Output

Tweets are classified into:

- 😀 Positive
- 😐 Neutral
- ☹️ Negative
